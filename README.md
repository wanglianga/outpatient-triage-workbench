# 候诊分流工作台

面向门诊护士、导诊台和患者服务人员的候诊分流页面，整合诊区队列、检查提醒、过号列表和拥堵状态于统一工作台。

## 原始需求

> 做一个给门诊护士、导诊台和患者服务人员使用的候诊分流页面，React + Vite 可以把诊区队列、检查提醒、过号列表和拥堵状态放在同一个工作台里。页面围绕挂号科室、医生出诊、患者签到、检查预约、诊室叫号、过号原因和候诊区座位展开。导诊台需要快速看出哪些患者已经签到、哪些正在检查途中、哪些过号后回到诊区、哪些老人或儿童需要优先引导；护士在页面上调整叫号顺序时，要能看到调整会影响哪些已等待患者。页面要突出诊区实时状态，队列、提醒、异常和患者详情之间切换要顺手，不能把所有信息堆成一张表。

## 功能特性

- **诊区实时状态**：各科室拥堵程度、医生出诊信息、候诊区座位使用率
- **叫号队列管理**：当前叫号展示、等待患者列表、拖拽调整叫号顺序
- **检查提醒**：待检查、检查途中、检查中、已完成状态跟踪
- **过号管理**：过号记录、原因标注、快速回归队列
- **患者详情**：点击查看患者完整信息、优先级、就诊记录
- **受影响预览**：调整队列顺序时实时显示将影响的患者范围

## 技术栈

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Zustand (状态管理)
- @dnd-kit (拖拽排序)
- lucide-react (图标)

## 启动方式

### 前置要求

- Node.js >= 18
- npm 或 pnpm

### 本地开发启动

#### 1. 安装依赖

```bash
npm install
```

#### 2. 启动开发服务器

```bash
npm run dev
```

访问地址：http://localhost:5173

### Docker 一键启动（推荐）

#### 前置要求

- Docker
- Docker Compose

#### 启动命令

```bash
docker compose up --build
```

后台运行：

```bash
docker compose up --build -d
```

访问地址：http://localhost:8080

停止服务：

```bash
docker compose down
```

## 使用说明

1. **查看诊区状态**：左侧面板展示各科室实时拥堵情况、候诊人数、座位使用
2. **叫号操作**：中间面板查看叫号队列，点击"叫下一位"呼叫下一位患者
3. **调整顺序**：拖拽患者卡片左侧的手柄调整叫号顺序，调整时会显示受影响患者数量
4. **检查管理**：右上方面板跟踪患者检查状态，可手动更新检查进度
5. **过号处理**：右下方面板管理过号记录，点击"回归队列"将患者重新加入队列
6. **患者详情**：点击任意患者卡片，右侧展开显示患者完整信息
